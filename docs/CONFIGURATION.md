# Portable configuration (development)

Prepare locally, then transfer private JSON to the destination Foundry v14 world.

1. Open Adventure Manager → Configuration Import / Export. Select features and mode.
2. Generate private JSON. The panel shows the filename and contents. Save file uses a save picker where supported, otherwise requests a browser download (the desktop app may not save it). Copy JSON or Select all JSON + Ctrl+C always provides a manual alternative: paste into Notepad, Save As, choose All files and the displayed .json filename. You can also paste directly into the destination configuration panel and click Load pasted JSON. Closing the panel clears the generated text and loaded data. Keep it private; it can contain adventure spoilers and GM notes.
3. For JSON-only files, upload custom images to Forge and map the paths. Alternatively import a preparation ZIP containing configuration.json and referenced assets/ images; the importer uploads the artwork to a new randomized folder through Foundry's FilePicker and uses returned paths. Validate & preview first and authorize asset uploads before applying. Assets are not secret merely because journals are private; anyone with the URL may be able to access an uploaded image.
4. Enable the same or newer development version on the destination. Back up the world first.
5. Choose the JSON file or load pasted JSON, supply any exact old-path → new-path replacements in a JSON object, then Validate & preview. Missing referenced images block apply.
6. Merge missing managed objects by default, or explicitly allow imported settings to update existing managed objects. Existing published evidence with a different snapshot is never overwritten. Campaign progress and publication require a separate opt-in. Refresh open feature panels after importing.

Modes: setup (scene import, initial view where available, cast, managed light geometry and core light settings, ambient baseline, trial target, subject, chase requirements, standard macro installation); preparation (also private evidence records and court text/image journals); campaign (also public snapshots, current board placements, trial exhibits/history and chase progress). Preparation never publishes evidence. Campaign imports without progress opt-in remain private. The original private draft and the public snapshot are separate data. Journal links are remapped to destination documents; historical withdrawn exhibits stay unavailable.

Limitations: one tagged scene per feature; export remains JSON only. Import supports preparation ZIP (80 MB compressed/uncompressed total, 12 MB per image, 8 MB JSON, 100 PNG/WebP/JPEG images; store or deflate). ZIP must contain configuration.json and only referenced assets/ lowercase image names, with no subfolders. No ZIP export yet. Uploads use a separate random folder and may remain after a failed import; actual Forge operation needs live testing. Court journal text is transferred as plain text with line breaks, not rich formatting, embedded links, arbitrary page types or ownership. Custom scene backgrounds, audio, arbitrary world settings, user hotbar positions, manual non-module objects and arbitrary macros are not transferred. Setup/preparation do not clear existing campaign progress. Replacement updates matching managed items, not a destructive world mirror; absent source items do not delete destination objects. Existing publication conflicts are skipped and reported. Missing assets are checked as GM, not proof of player asset access. Import is sequential and not transactional; a failed write may leave partial results. Use one GM client and a disposable world first. Future feature adapters should add explicitly validated data to the portable format and migration tests. Never bundle published adventure material, campaign evidence, or private preparation files in the distributable module.

Suggested test: create a private draft with a unique GM note, publish an older snapshot, change the draft, place evidence and cast, adjust lights and chase requirements. Export preparation and campaign separately. Import preparation into a clean world; verify the draft exists, private note is private, and no public snapshot is created. Import campaign with explicit progress opt-in into another clean world; verify remapped journal links and the public snapshot does not contain the later private edit. Import again in merge mode; verify no duplicates. Test missing image blocking and remapping, and test with a normal Player account.
